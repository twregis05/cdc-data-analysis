# Project checklist

## 1. Decide up front

- [X] Language setup (Python / R)
- [ ] Shared repo
- [ ] Folders
- [ ] Tooling
- [ ] Owners
- [ ] Weekly check-in

## 2. Choose a dataset

- [ ] Brainstorm topics
- [ ] Shortlist
- [ ] Check size and messiness
- [ ] Target variable
- [ ] Group comparisons
- [ ] License
- [ ] One-sentence question
- [ ] Download to data/raw

## 3. Explore and clean

- [ ] Inspect
- [ ] Missing values
- [ ] Duplicates
- [ ] Standardize text
- [ ] Impossible values
- [ ] Outliers
- [ ] New columns
- [ ] Log changes
- [ ] Save clean file
- [ ] Summary stats
- [ ] Distributions
- [ ] Correlations
- [ ] Target vs. predictors
- [ ] Note 3 to 5 patterns

## 4. Visualizations

- [ ] List charts
- [ ] Choose chart types
- [ ] Build in Tableau
- [ ] Clear labels and color-blind-safe colors
- [ ] Dashboards
- [ ] Model figures in R or Python
- [ ] One takeaway per chart
- [ ] Publish to Tableau Public
- [ ] PNG backups

## 5. Hypothesis tests

- [ ] Turn patterns into hypotheses
- [ ] Set alpha first
- [ ] Pick tests
- [ ] Check assumptions
- [ ] Effect sizes
- [ ] Multiple-comparison correction
- [ ] Plain-language conclusions

## 6. Model

- [ ] Define task and metric
- [ ] Train/test split with seed
- [ ] Preprocessing in pipeline, fit on training data only
- [ ] Check for leakage
- [ ] Baseline
- [ ] Stronger models
- [ ] Cross-validated tuning
- [ ] One final test evaluation
- [ ] Residuals or confusion matrix
- [ ] Save model

## 7. Feature-importance check

- [ ] Permutation importance
- [ ] Top-10 plot
- [ ] Compare with exploration
- [ ] Investigate mismatches
- [ ] Partial dependence
- [ ] Write the explanation

## 8. Report

- [ ] Outline
- [ ] Write each section
- [ ] Embed Tableau and figures
- [ ] Export script rerun
- [ ] Accessibility
- [ ] Proofread
- [ ] Publish on GitHub Pages

## 9. Optional d3 dashboard

- [ ] Decide whether to build it
- [ ] Build and link from the site

## 10. Final check

- [ ] Rerun from raw
- [ ] Numbers match
- [ ] README complete
- [ ] No secrets
- [ ] Links work
- [ ] Dataset cited
